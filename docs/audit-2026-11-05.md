# Research integrity audit

## Scope

Prepared 5 November 2026 from base 3c90ec2. Version 0.2.0rc1 is an unpublished
implementation candidate. Independent verification, merge and release are separate.
The original suite passed 198 tests. A separate 28-case synthetic audit reproduced
28 failures before repair. The original probe and before/after logs are preserved
in the local handoff; the cases are committed as regression tests.

## Corrections

| Area | Confirmed problem | Correction |
| --- | --- | --- |
| Accuracy | Broadcast, nonbinary, nonfinite or empty target arrays could give misleading accuracy. | Require nonempty matching real vectors and binary targets. |
| Aggregation | Boolean/string values were coerced to numbers; invalid intermediate history could be ignored. | Typed finite metrics, complete configurations, known regimes and every generation validated. |
| Factorial summaries | Unknown arms, boolean generation IDs and out-of-range intermediate metrics could enter reporting. | Complete paired cohorts and every history cell are validated. |
| Checkpoints | Invalid RNGs, duplicated ancestry, out-of-horizon boundaries and mixed tensor precision were accepted. | Validate all saved components before constructing agents or executing a segment. |
| Module modes | Root training mode hid differing submodule modes in saved states and fingerprints. | Schema 2 saves every module mode; fingerprints include them. |
| Continuation | A changed learning configuration could silently replace the checkpoint's fixed settings. | Require exact typed configuration; explicit Controls remain the intervention interface. |
| Configuration | Duplicate YAML keys silently chose the last setting. | Unique string keys and bounded input. |
| Artifacts | Ordinary writes could truncate previous results on failure. | Atomic replacement, exclusive checkpoint/ledger publication and preflight collisions for historical runners. |

## Compatibility

Public evolution APIs and paired-v1 numerical dynamics are retained. Complete valid
legacy configurations and results remain supported. Boolean metrics, coerced string
numbers, incomplete records and contradictory inputs are deliberately rejected.
Old schema-1 checkpoints can be loaded with the old uniform-root-mode assumption;
new schema-2 checkpoints retain individual module modes and are validated strictly.
The checkpoint fingerprint format changes because it now binds those modes and
schema. Preserve old files and use their original source environment when replaying
an interrupted legacy experiment. Do not mix fingerprints across implementations.

Continuation must keep the EvolutionConfig fixed. Controls may explicitly change
selection, trait mutation and branch freezing at a boundary. The runner still resets
Adam each generation. CPU float32/float64 model states are supported; checkpoints
with unsupported or inconsistent precision are rejected rather than silently cast.

Experiment output destinations must not already contain the target artifacts.
A completion manifest is written only after all expected records exist. Failed
ordinary writes preserve previous files, but this is not a crash-durable transaction
for an entire multi-file experiment. Keep separate directories for concurrent runs.
Interrupted new-format runs may resume only with unchanged source/runtime/settings
and internally consistent completed ledgers. Incomplete files are never overwritten.

## Verification boundaries

The new local study has all 14 arms for five prospective roots. Each source-level
validation test is part of the implementation evidence, not independent external
certification. Prompt 2 must challenge the implementation and reproduce findings
from a fresh checkout, including the new per-agent record checks.

The package now includes experiment modules for installed execution outside a
checkout. CI covers Linux Python 3.10 through 3.14, macOS 15, a known-advisory audit
of recorded dependency versions and a gated fresh-wheel installation. The reference
pins are not a hash-locked universal dependency environment. The package requires
only the previously declared PyTorch, NumPy, Matplotlib and PyYAML runtime families.

All historical checked result files and original configuration files are preserved.
No private repository or model service is involved. All data is synthetic.

## Cross-platform arithmetic check

The first hosted run passed all source tests but Linux rejected a Mac-produced
ancestry ledger. An isolated comparison reproduced a one-ULP difference in
Python random.gauss: -0.3612772269036275 on the Mac and -0.3612772269036276 on Linux
for the same root, stream and draw. Typed ancestry comparison now permits only
1e-12 absolute/relative float roundoff. All keys, identifiers, integer counts,
booleans, generator-state bits, file hashes and checkpoint fingerprints remain
exact. Tests reject larger changes and numeric type aliases. No evidence check
was removed. Original failed hosted logs are retained in the review handoff.
